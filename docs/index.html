entra-sim

A simulator of the Microsoft Entra ID identity endpoints and the Microsoft Graph API, written in Rust.

entra-sim lets code and infrastructure that depend on Entra run locally and in CI, without a real tenant, credentials, or a shared directory. An existing client, whether application code, an Azure SDK, MSAL in a browser or a Terraform configuration, is pointed at it by changing configuration only.

Quick start

From a checkout, ./run.sh builds the image, starts the container, waits until it is healthy and opens the studio at http://localhost:8080/. To run the published image instead:

mkdir -p certs
docker run --rm --user "$(id -u):$(id -g)" \
  -p 127.0.0.1:8080:8080 -p 127.0.0.1:8443:8443 \
  -v "$PWD/certs:/certs" \
  ghcr.io/gosogco/entra-sim:latest

until curl -sf -o /dev/null http://127.0.0.1:8080/__sim__/health; do sleep 1; done

curl --cacert certs/ca.pem \
  -d grant_type=client_credentials \
  -d client_id=11111111-1111-1111-1111-111111111111 \
  -d client_secret=entra-sim-bootstrap-secret \
  -d 'scope=https://graph.microsoft.com/.default' \
  https://localhost:8443/00000000-0000-0000-0000-000000000001/oauth2/v2.0/token

Security

The simulator has no real authentication. The bootstrap secret is public, and GET /__sim__/snapshot returns every secret it holds. Keep its ports on 127.0.0.1, as the commands above do, and never put real credentials in it.
